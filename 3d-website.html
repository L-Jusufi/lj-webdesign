Häufige Fragen

Wird meine Website dadurch langsam?

Nein. Das Modell wird so klein wie möglich gemacht und lädt erst, wenn ein Besucher dorthin scrollt. Der Rest der Seite bleibt schnell.

Woher kommt das 3D-Modell?

Oft gibt es schon Daten aus der Planung, zum Beispiel CAD-Dateien oder Modelle vom Hersteller. Wenn nicht, erstelle ich ein passendes Modell anhand von Fotos und Plänen.

Funktioniert das auf dem Handy?

Ja. Das Modell lässt sich mit dem Finger drehen. Ich teste jede Lösung auf Handy, Tablet und Computer.

Kann ich 3D auch nur auf einer Seite einbauen?

Ja, das ist sogar oft am sinnvollsten: zum Beispiel ein Konfigurator auf der Produktseite, während der Rest der Website normal bleibt.
